# podcast-source-forensics
从播客逐字稿快速定位国外原文并形成可复核证据链（以独树不成林播客为例）

因仲树老师被披露洗稿之后，仍旧连发三篇洗稿内容，故此整理了一个skill。

这是一个用于播客来源核验的 Codex Skill。它可以获取公开播客音频，通过使用者自己的飞书妙记生成逐字稿，并从罕见表达、概念组合和论证结构中快速定位可能的国外著作、论文、课程或播客来源。

Skill 会生成带时间戳的证据表，区分一手材料、思想相近和结构性改写，并计算来源覆盖时长。所有结论均属于公开材料的文本取证，不构成法律意义上的抄袭或侵权认定。

**诉求：**
**希望仲树老师洗稿的时候加上出处，并不再公共场合对原创作者嗤之以鼻，因为你不原创；
希望仲树老师的粉丝通过本skill能取得一手智识，除了蹭主播的虚名外，能真的有自己的心得和见识。**

使用时调用：$podcast-source-forensics

我对仲树老师的温柔：**必须排除的内容**

- 小说、戏剧、电影、历史文献或受访者本人说出的原句。
- 剧情、人物关系、历史年代、作者、译者、版本等可直接查得的事实。
- 领域内高度常见的分析母题。**
- 主播已经在口头、简介或 show notes 中明确披露并进行正常引用的来源。**
- 不可访问正文、只有搜索结果摘要的材料。


需要安装 lark-cli。
每个人使用自己的飞书配置，不包含现成API或凭据。
音频会上传到使用者自己的飞书云空间。
安装时把内层 podcast-source-forensics 文件夹放进 $CODEX_HOME/skills 或 ~/.codex/skills。
调用方法：$podcast-source-forensics。
“洗稿”结论属于文本取证，不构成法律认定。
