# 30分钟国外来源检索法

## 目标

在30分钟内完成“可疑段落初筛”，找到最可能的国外课程、播客、论文、图书或评论来源，并形成足以继续复核的时间戳证据表。30分钟是快速定位目标，不保证每个个案都能最终定性。

## 0-5分钟：音频与逐字稿

1. 保存节目元数据和总时长。
2. 把公开音频提交飞书妙记。
3. 转写等待期间阅读节目简介、章节标题和公开参考链接。
4. 不用简介替代完整逐字稿；简介只能帮助确定主题和专名。

## 5-10分钟：提取来源指纹

快速通读逐字稿，记录 8-15 个高价值锚点，优先级如下：

| 优先级 | 锚点 | 例型 |
|---|---|---|
| P0 | 主播直接念出的外文原句或独特术语 | 6-12个连续词、冷门概念、特殊比喻 |
| P0 | 罕见概念组合 | 概念A + 概念B + 特定人物/案例 |
| P1 | 论证顺序 | 先提出方法，再连续经过三个人物，最后回到同一意象 |
| P1 | 反常识解释 | 普通事实被转成一个并不显然的制度、心理或政治判断 |
| P2 | 常见主题 | 单独价值低，只有与其他锚点成组时使用 |

同时标出开篇方法论、段落转折和结尾收束。洗稿经常会改写句子，却保留“提出问题 -> 举例 -> 概念转换 -> 结尾回扣”的结构。

## 10-20分钟：搜索候选来源

### 查询构造

依次尝试：

1. 外文原句加引号搜索。
2. 两个罕见英文概念加作者、作品、人物或主题。
3. 三个人名/案例的组合搜索。
4. 把中文判断反译成两到三种简洁英文表达，再与冷门专名组合。
5. 在已发现的候选来源站点内搜索第二个锚点，验证是否出现连续命中。

不要只搜宽泛主题。单个常见词的相似性几乎没有来源辨识度。

### 来源优先级

| 级别 | 来源 | 用法 |
|---|---|---|
| A | 官方课程/播客页面、官方字幕、大学和研究机构页面 | 可直接作为主要证据 |
| A | 作者稿、出版社页面、可核页码的公开论文全文 | 可直接作为主要证据 |
| B | 合法图书预览、可靠学术数据库摘要 | 用于确认书目信息或发现正文线索 |
| C | 普通书评、二手摘要、搜索结果摘要 | 只用于导航，不能独立支撑强结论 |

一旦某来源命中两个以上罕见锚点，不要继续无边界扩搜。立即进入全文，检查论证上下文、出现顺序和节目相邻段落。

## 20-27分钟：全文对齐

对每个候选来源回答：

1. 来源是否真的提出了节目中的解释，还是只用了相同名词？
2. 两者是否共享不常见的概念组合、人物顺序、例证链或结尾回扣？
3. 这些内容能否直接来自一手作品、公共事实或领域常识？
4. 节目是否披露或口头致谢了该来源？
5. 能否给出来源时间戳、页码、段落位置和稳定 URL？

每条只摘录足够证明匹配的短句。不要复制整页、整章或完整字幕。

## 27-30分钟：定级与覆盖率

1. 按证据标准给每条匹配分类。
2. 单独列出一手材料和公共事实，明确“不计入洗稿证据”。
3. 合并重叠节目区间，计算严格和扩展覆盖率。
4. 写一段可证伪的结论：指出核心候选来源、它覆盖的论证链、仍不能证明的事项。

## 快速停止规则

- 只找到主题相近、没有独特组合：停止升级，结论为“证据不足”。
- 找到搜索摘要但打不开正文：保留为线索，不列强证据。
- 多份文献共享同一传统：写“来源网络”，不要冒充唯一来源。
- 节目已明确引用或致谢：记录披露情况；不能把正常引用直接称为洗稿。
- 没有完整逐字稿：只做线索初筛，不计算覆盖率，不下高置信度结论。

## 推荐检索记录

保留以下字段，便于其他人复跑：检索时间、查询式、命中 URL、未命中锚点、访问限制、候选来源状态（排除/待核/已核）。检索记录不应包含登录凭据、Cookie 或私人浏览数据。
